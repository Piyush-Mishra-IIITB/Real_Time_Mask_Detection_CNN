**-Time Mask Detection App (CNN-based)**

This is a web-based application that detects whether a person is wearing a mask or not in real-time using Convolutional Neural Networks (CNNs). The app is built with Streamlit, OpenCV, and TensorFlow/Keras.

Features

Detects Mask / No Mask using a CNN model trained on facial images.

Supports real-time prediction via webcam input.

Automatically downloads the trained CNN model from Google Drive.

Displays prediction results only, keeping the interface simple and clean.
